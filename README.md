# GigaChat AI Studio — практикум Клуба ИИИИ

[Открыть презентацию](https://alekstravin.github.io/gigachat-club-workshop/) · [Пошаговое руководство](https://alekstravin.github.io/gigachat-club-workshop/guide.html) · [Промпты](https://alekstravin.github.io/gigachat-club-workshop/prompts.html)

86 слайдов с реальными GIF интерфейса, простым агентом, RAG, новостником, Python, генерацией изображений и сравнением платформ.

Папка downloads содержит учебные схемы JSON и код. Импорт требует своей авторизации и, для отдельных сценариев, настройки источников и локального сборщика. Ссылки на агентов открываются с учётом прав доступа в Studio. Сборщик новостей работает локально: GitHub Pages исполняет только статические страницы.

Скачайте workshop-offline.zip, распакуйте и откройте index.html. Учебные файлы не содержат API-ключей. Дополнения по отдельному обучающему видео пока не включены и ожидают согласования.
