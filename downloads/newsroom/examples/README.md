# Учебные примеры новостника

## Синтетические локальные тесты
`synthetic-unsigned-example.json` содержит написанные нами вымышленные материалы, условные example.org URL и явно обозначенные mock-поля даты/HTTP/верификации. Эти URL не скачивались. Файл не подписан и не должен проходить production-проверку. Это форматный пример, не новости.

`../test_pipeline.py` при каждом запуске создаёт временный RSA-ключ только в памяти, подписывает новый синтетический пакет и подставляет открытый ключ только в тестовое пространство имён неизменённого валидатора. Пользовательский ключ и production-схема не меняются. Проверяются 11 условий подписи, блокировки, JSON, цитаты и русского языка. Итог записывается в `synthetic-test-results.json`. Эти тесты не проверяют сеть, свежесть реальных статей или качество LLM.

## Метаданные реального прошлого запуска
`real-run-metadata.json` — URL, заголовки, даты и время проверки реального авторского запуска за 25 октября 2026; тела статей и исходные цитаты исключены. `verification.json` — сохранённый журнал того же запуска. `russian-v5.txt` — русский пересказ и оценки модели; `digest.md` — наш краткий обзор. Это исторические результаты, а не новая проверка доступности сайтов.

Полный исходный подписанный пакет сохранён в исходном проекте автора, но не рассылается с учебными материалами. Для собственного живого теста настройте ключ через setup_newsroom.py и заново соберите публикации collector.py; затем передайте целый пакет персональному агенту.
