## Как пользоваться

1. Если сборщик не открывается, запустите файл «Запустить сборщик.command». Терминал держите открытым.
2. В сборщике выберите календарную дату и нажмите «Найти и проверить».
3. Нажмите «Скопировать проверенный пакет».
4. Откройте агента Studio → «Открыть чат», вставьте пакет и отправьте. Нужен именно полный JSON, без дополнительного текста.
5. Studio проверит происхождение пакета, даты, ссылки и наличие текста; затем GigaChat сделает русский пересказ. Финальный Python проверит буквальную цитату в оригинале, набор карточек, отсутствие новых URL и чисел.

Пакет передаётся вручную между двумя частями. Один запрос «за 25 октября» внутри Studio сам по себе не запускает внешний сборщик. Автоматический мост не подключён.

## Устройство схемы

Ввод пакета → Python проверки подписи/метаданных → If-Else PASS/BLOCK → подготовка текста с сохранением оригинала → GigaChat → Python проверки цитаты и выпуска → чат. BLOCK ведёт прямо к сообщению об отказе. 8 нод, 8 связей.

В Studio хранится только открытый ключ проверки. Закрытый ключ подписания находится отдельно от проекта, в локальном пользовательском каталоге с правами 600, и не включён в экспорт агента. Статус проверки, написанный LLM, не даёт допуска.

## Практические пределы

- Текущий охват — два доступных англоязычных издания; третий настроенный источник недоступен. Это не полный мировой или российский мониторинг.
- Поиск использует архивный WordPress API, до 100 записей на источник за день; тематический фильтр — по заголовку. Новые сайты требуют отдельных адаптеров.
- Дата — календарный день у издателя; часовые пояса не приводятся к московскому дню.
- Подтверждается наличие публикации, её дата, URL и полученный текст. Истинность каждого утверждения СМИ и аналитические выводы LLM независимо не устанавливаются.
- Совпадение одной цитаты и чисел — дополнительная защита, не полная семантическая проверка русского пересказа.
- Сборщик запущен только на 127.0.0.1. С iPhone эта локальная страница недоступна; публичный доступ и публикация не настраивались.

## Подготовлен перевод внутри агента — v5

В v5 сам GigaChat при каждом запуске переводит заголовок в title_ru и пишет пересказ/анализ по-русски. Python выводит title_ru вместо исходного английского заголовка; исходные URL, компании и проверочные цитаты не подменяются. Английский заголовок, пересказ или анализ без кириллицы блокируют выпуск. Это базовая проверка языка, а не доказательство точности перевода.

JSON для импорта: 09-russian-newsroom-v5.json. Локально пройдены 11 проверок, включая отклонение английского текста в трёх полях. После повторного входа v5 импортирована отдельным агентом. Старый v4 сохранён для сравнения; живой тест русского выпуска завершился: заголовки, пересказы, аналитические оценки и статусы выданы по-русски. После первого прогона добавлен терминологический словарь для SPA, Term Sheet, MMBtu и инвестиционных обязательств.
