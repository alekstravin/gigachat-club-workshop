# Новостник «Газ и СПГ»: перенос на свой компьютер

Этот комплект соединяет **внешний Python-сборщик** и **агента в GigaBlocks**. Сборщик сам ищет публикации заданного дня, проверяет HTTP, метаданные даты и совпадение текста, затем подписывает пакет. Studio проверяет подпись, пересказывает и переводит принятые статьи, проверяет структуру выпуска. Сетевой поиск внутри Python-блока Studio здесь не используется.

## Что нужно

Python 3.10 или новее, интернет для установки `cryptography` и обращения к источникам, браузер и вход в AI Studio. Папка `newsroom` должна оставаться рядом с `../newsroom-agent.json`: это исходная схема. Не запускайте старый `build_studio.py` из другого проекта — он привязан к авторскому окружению. Его копия намеренно не включена в этот переносимый комплект; исходный проект автора сохранён отдельно.

## macOS / Linux

Откройте терминал **в этой папке `downloads/newsroom`** (путь может содержать пробелы — заключайте его в кавычки):

```sh
cd "/ваш/путь/к/downloads/newsroom"
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python setup_newsroom.py
```

Скрипт создаст `generated/news-agent-personal.json`. Импортируйте **его**, а не исходную `../newsroom-agent.json`, как нового агента в Studio. В меню импорта выберите создание новой копии и проверьте связи.

Запустите сборщик:

```sh
python server.py
```

На Mac после настройки можно также дважды нажать `run_collector.command`. Он определяет свою папку, предпочитает `.venv/bin/python3` и не требует авторского абсолютного пути.

## Windows / PowerShell

Откройте PowerShell в этой папке:

```powershell
cd "C:\ваш\путь\downloads\newsroom"
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_newsroom.py
.\.venv\Scripts\python.exe server.py
```

Активация PowerShell-скрипта не требуется: команды используют Python окружения напрямую. Если команда `py` отсутствует, используйте установленный `python` для создания окружения. Импортируйте `generated\news-agent-personal.json` в Studio как нового агента.

## Проверка за 25 октября 2026

Откройте **http://127.0.0.1:8275** на том же компьютере. Выберите дату **2026-10-25**, нажмите «Найти и проверить», дождитесь результата и скопируйте подписанный пакет. Вставьте **пакет целиком** в чат нового персонального агента Studio. Этот ручной перенос — предусмотренный мост между сборщиком и облачным агентом; само наличие окна сборщика не означает интеграцию по сети со Studio.

Можно отдельно запустить сборщик без сервера:

```sh
python collector.py --date 2026-10-25
```

В PowerShell:

```powershell
.\.venv\Scripts\python.exe collector.py --date 2026-10-25
```

Пакет появится в `runs/2026-10-25/verified-packet.json`, журнал — в `verification.json`, краткая подборка — в `digest.md`. Если источники изменились, доступны не все публикации или нет принятых статей, результат может отличаться от сохранённого примера. Пустой или недействительный пакет должен привести к остановке выпуска, а не к выдуманным новостям.

## Ключи и перенос

`setup_newsroom.py` вызывает штатную `collector.signing_key()` и получает из неё **только открытые числа n и e** для конфигурации проверяющего блока. Закрытый ключ создаётся/загружается самим сборщиком в домашней папке пользователя: `.local/share/club-lng-collector/signing-key.pem`. В package и экспорт агента он не копируется и не печатается. На Unix сборщик выставляет права 600; на Windows защита файла также зависит от прав домашней папки.

Скрипт сохраняет открытый ключ в `generated/public_key.json` и `public_key.json`, обновляет открытые константы `PUBLIC_N`/`PUBLIC_E` в локальном `verify_evidence.py` и в новом `generated/news-agent-personal.json`. **Исходная `../newsroom-agent.json` не меняется.** Повторная настройка использует тот же локальный ключ. После удаления/замены ключа нужно повторить setup и заново импортировать полученную схему; старые пакеты не пройдут новую проверку.

В `examples/real-run-metadata.json` сохранены URL, заголовки, даты и время реального прошлого запуска; тела статей и исходные цитаты исключены. Журнал и русский пересказ также включены как исторические материалы. Полный прежний подписанный пакет остаётся в исходном проекте автора и не рассылается с уроком. `synthetic-unsigned-example.json` — явно вымышленный форматный пример с example.org URL и mock-полями, без подписи; он не должен проходить production-проверку. Для собственного живого теста заново запустите сбор.

## Ограничения и остановка

- Сборщик обращается только к настроенным источникам: Just Energy News, Midstream Calendar, EnergyNow. В авторском тесте два сайта дали три публикации, третий вернул 403. Это не полный мониторинг газовой отрасли.
- Архивный поиск ограничен 100 записями на источник за день, тема отбирается по заголовку; верификация обрабатывает ограниченный набор кандидатов. Новые сайты требуют адаптеров.
- Дата — календарный день публикации у издателя. Дата события может быть иной; московский часовой пояс автоматически не подставляется.
- HTTP 200, дата, текст и подпись не доказывают истинность каждого утверждения СМИ. Оценки LLM нужно читать отдельно от фактов источника. Проверка русского языка и цитат — ограниченная защита, не полная семантическая экспертиза.
- Сервер слушает только `127.0.0.1`; iPhone с ним напрямую не соединится. Публичный хостинг не настроен. Не заменяйте адрес на `0.0.0.0` без отдельной настройки доступа.
- Если порт **8275 занят**, не завершайте чужие процессы. Возможно, уже запущен прежний сборщик: откройте адрес и проверьте. Остановите своё окно сервера клавишами Ctrl+C либо разберитесь с владельцем порта.
- Обычный `README.md` сохранён как историческое описание разработки; для переноса следуйте этому файлу. `test_pipeline.py` теперь выполняет 11 синтетических локальных проверок: создаёт RSA-ключ только в памяти и подставляет открытый ключ только в тестовое пространство имён валидатора. Пользовательский ключ, исходная схема и production-константы не меняются. Запуск: `python test_pipeline.py` (Windows: `.\.venv\Scripts\python.exe test_pipeline.py`). Это проверка подписи, блокировки, JSON, цитаты и русского языка, а не сети, свежести настоящих статей или качества LLM.
