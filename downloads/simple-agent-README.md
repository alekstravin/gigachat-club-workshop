# Помощник ведущего — итоговая схема

simple-agent.json — производная реального нативного экспорта простого агента. В нём обновлено одно значение системного промпта (Prompt Template → template.value) из simple-system-prompt.txt; сохранены идентификаторы, компоненты и связи. Предназначенные для credentials/session/context/trace поля очищены. Исходный нативный экспорт в Downloads не менялся. Запись чата оставлена включённой.

Импортируйте как нового агента, проверьте модель и связи. Положительный запрос с темой должен дать цель, упражнение из трёх действий, проверяемый результат и вопрос обсуждения. На «Привет» ожидается уточняющий вопрос о теме; на просьбу свежих новостей без источников — отказ от выдумывания. Финальная инструкция прошла все три живых теста: обычный вопрос с темой, приветствие без темы и запрос неподтверждённых новостей. Положительный ответ содержит четыре запрошенные части, три действия и проверяемый результат — таблицу «Абзац / Ответ ИИ / Оценка / Комментарий». Кадр simple-14-final-positive.png сохраняет видимый результат повторного положительного теста.

Полезная отладка показана отдельно в simple-debug.gif: неудача старой инструкции → усиление порядка → повторный тест. Это сохранённые реальные кадры, а не обещание из промпта.

Финальная копия JSON импортирована 28.10.2026 в отдельный тестовый агент c402a5df-d935-481e-9013-bd261a848ee6: сохранены три связи; на «Привет» получено «Какую тему встречи Клуба вы хотите разобрать?». Полные три сценария проверены в основном агенте с тем же промптом.
