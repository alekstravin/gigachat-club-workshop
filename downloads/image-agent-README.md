# Газовая отрасль: иллюстратор

image-agent.json — повторная сборка текущей рабочей схемы из компонентов реального нативного экспорта Studio «Генерация изображений» и экспорта «Клуб ИИИИ — Помощник ведущего». Это не прямой нативный экспорт текущего канваса.

6 узлов, 5 связей: ChatInput → GigaChatModel → GigaChatImage → Prompt Template {image} → ChatOutput; отдельный Prompt Template → system_message модели. Выбранный штатный стиль: «По умолчанию» / пустое значение. Рекомендуемый проверенный путь: оставить его и явно написать в запросе «Стиль: акварель. Нарисуй СПГ-газовоз у терминала…». Этот запрос дал реальную акварель; действующий системный промпт сохраняет явно указанный стиль. Штатный preset «Акварель» дважды был отклонён фильтром, «Карандаш» дал фотографический результат, поэтому наличие пункта меню не является гарантией стиля или успеха. Прежний результат 3D тоже подтверждён. Доступные пункты меню сохранены из реального шаблона, шесть проектных стилей из image-agent-design не подменяют их.

Картинка не гарантированно отображается inline в чате. Штатный просмотр результата: нажмите время выполнения блока «Генерация изображений» → Outputs → «Изображение» → «Скачать». Внешний image-viewer.html — дополнительный способ посмотреть data:image и скопировать запрос с префиксом выбранного стиля; это отдельный учебный интерфейс, а не штатное меню чата Studio. Учётные данные, session/context/trace ID очищены в предназначенных для них полях; всё равно проверьте копию перед распространением. Базу знаний этот агент не использует.

Воспроизведение:
```sh
python3 build_image_agent.py --image-template native-image.json --simple-template native-simple.json --prompt-file image-system-prompt.txt --output image-agent-rebuilt.json
```
Импортируйте как нового агента и протестируйте. Для ChatInput и ChatOutput сохранено should_store_message=true: выключение записи приводило к пустому отображению чата даже после выполнения схемы. Прошлые тексты проб и session/context ID очищаются отдельно; это не повод выключать отображение истории. Сборка JSON не является подтверждением успешного запуска.

simple-agent.json — производная нативного экспорта простого агента: один системный промпт обновлён из simple-system-prompt.txt до финального строгого порядка. Дополнительно очищены предназначенные для credentials/session/context/trace поля. Исходный нативный экспорт в Downloads не изменён.
